# Sales & Profit Analysis

An Excel-based sales and profit analysis project designed to track business performance and identify useful sales insights.

## Tools Used
- Microsoft Excel
- Formulas
- Data analysis
- Dashboard & charts

## Key Metrics
- Total Revenue
- Total Profit
- Total Units Sold
- Average Profit per Unit
- Monthly Revenue

## Analysis
The project analyzes sales data across different months, products, and sales channels to understand revenue and profitability.

## Files
- `sales_profit_analysis.xlsx` — Excel workbook containing the sales data and dashboard.
